Android player

Turn any screen into an Adextry screen.

The Adextry Player is a small Android app. Plug an Android box or stick into your screen, install the app, enter a pairing code, and your screen starts showing approved ads.

Ask us for the player Register as a screen owner
What you need

Four things, and you are ready.

01

An Android box or stick

Any reliable Android TV box or stick running Android 8.0 or newer.

02

A screen with HDMI

A TV, monitor or billboard display that takes an HDMI input.

03

Internet

Wi-Fi or Ethernet to sync. Ads are saved on the box, so short outages do not matter.

04

A screen owner account

A verified Adextry account with your screen listed in the dashboard.

Setup

Set it up in five steps.

Most screens are online in about ten minutes.

01

Download the player

On the Android box, download the Adextry Player APK, or copy the file over from a USB drive.

02

Install it

Open the file. When Android asks, allow installs from unknown sources for the app you used to open it. The wording differs from box to box. Then tap Install.

03

Open it and read the code

Open Adextry Player. The screen shows a pairing code like ABC-1234. Make sure the box is connected to the internet.

04

Pair it in your dashboard

Go to Billboards, open your screen, choose Pair device and type in the code. The box pairs within seconds.

05

It starts playing

The box downloads approved campaigns, plays them inside their daily hours and reports every play back. Ads keep playing if the internet drops.

Optional

Lock the box into kiosk mode

For an unattended screen, make Adextry Player the box's device owner. It stays on screen, starts itself again after a power cut, and nobody can leave the app.

Do this on a freshly reset box with no Google account added, using a computer with adb. If you are unsure, skip it. The normal install works fine.

adb shell dpm set-device-owner \ com.adextry.adextryplayer/.device.AppDeviceAdminReceiver
Good to know

Questions about the player.

Which box should I buy?
Any reliable Android TV box or stick with Android 8.0 or newer and an HDMI output. If Wi-Fi at your site is weak, choose one with an Ethernet port.
The pairing code does not show up.
Check that the box is connected to the internet, then close and reopen the app. The code appears once the box can reach Adextry.
Why is the screen black?
The player only shows approved campaigns, and only inside each campaign's daily hours. If nothing is approved for that hour, the screen stays dark. Check your dashboard for upcoming campaigns.
What time does the player use?
Your screen's own timezone from the dashboard, not the box's timezone setting. The box's clock still needs to be correct, so keep it connected to the internet.
What happens after a power cut?
The player starts again on its own when power returns. Kiosk mode makes the restart the most reliable.
How do I move a box to another screen?
Unpair the device in your dashboard. The box goes back to showing a pairing code, and you can pair it with a different screen.
How do I update the player?
Install the newer APK over the old one. The box stays paired.
